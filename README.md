# Sudhanshu Tiwari - Personal Portfolio Website

A modern, responsive personal portfolio website for Sudhanshu Tiwari, a Developer Relations enthusiast, software engineer, and community builder based in Jaipur, India.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Dark/Light Mode**: Toggle between dark and light themes
- **Modern UI**: Clean, minimal design with smooth animations
- **Optimized Performance**: Fast loading and smooth scrolling
- **Accessibility**: Designed with accessibility in mind
- **Interactive Elements**: Dynamic project filtering, form validation, and more

## Sections

1. **Home**: Professional introduction with call-to-action buttons
2. **About**: Personal bio, focus areas, and contact information
3. **Skills**: Technical and community-building capabilities
4. **Community**: Events organized, attended, and community involvement
5. **Experience**: Professional journey and work history
6. **Projects**: Showcase of technical projects with filtering options
7. **Blog**: Articles and speaking engagements
8. **Contact**: Contact form and social media links

## Tech Stack

- HTML5
- CSS3 (with custom properties for theming)
- JavaScript (vanilla, no frameworks)
- Font Awesome for icons
- Google Fonts (Inter)

## Setup and Usage

1. Clone the repository
2. Open `index.html` in your browser
3. To make changes:
   - Edit HTML in `index.html`
   - Modify styles in `css/custom.css`
   - Update functionality in `js/main.js`
   - Add images to the `images` directory (see the README in the images folder)

### Profile Images
The portfolio uses stylish placeholders with your initials if profile images are not available. To add your own images:
1. Add `hero.png` for the hero section
2. Add `about.jpg` for the about section

## Customization

- **Colors**: Update the CSS variables in `:root` in `custom.css`
- **Content**: Replace the placeholder text and images with your own
- **Projects**: Add or remove projects in the projects section
- **Blog Posts**: Update the blog section with your own articles
- **Contact Form**: Connect the form to your preferred backend service
